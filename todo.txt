Make the calculator work! You’ll need to 
store the first and second numbers input by the 
user and then operate() on them when the user 
presses the = button, according to the operator 
that was selected between the numbers. 

You should already have the code that can 
populate the display, so once operate has been 
called, update the display with the result of the 
operation.

This is the hardest part of the project. You need to figure out how to store all the values and call the operate function with them. Don’t feel bad if it takes you a while to figure out the logic.
